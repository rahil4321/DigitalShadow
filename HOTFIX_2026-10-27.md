# Frontend hotfix — 27 October 2026

## Symptom
After `POST /api/scenario/simulate` returned HTTP 200, the Scenario Studio went blank with:

`TypeError: Cannot read properties of undefined (reading 'field')` in `ScenarioStudio.jsx` around the assumption-provenance ledger.

## Cause
The provenance formatter accidentally referenced `item.item.field`; each provenance row is already `item`, so the nested object does not exist.

## Fix
- Changed the formatter to use the row's `field` property directly.
- Moved the formatting rules into a defensive helper.
- Guarded the provenance rendering against malformed/missing rows.
- Added a React error boundary around Scenario Studio so a future render exception produces a recovery screen instead of a blank page.

## Apply to an existing checkout
In `frontend/src/ScenarioStudio.jsx`, search for `item.item.field`. It should not appear in the fixed release. Restart Vite or refresh the browser after applying the corrected file.

## Validation
- Full Python test suite: 96 passed.
- JSX source reviewed after patch; the environment used for this hotfix has no cached npm packages and cannot perform a clean Vite production build offline. Run `npm ci && npm run build` in the frontend directory on your machine to complete the frontend build check.
